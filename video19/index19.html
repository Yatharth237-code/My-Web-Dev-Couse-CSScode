Fonts

There are many different fonts available for use on the web.

Fonts can be specified using the CSS 'font-family' property.

The 'font-family' property allows you to specify a list of fonts, and the browser will use the first one that is available on the user's system.

You can also specify a fallback font in case the primary font is not available.
